# Plan Desk

Drawing review, markups and takeoffs for PDF drawings — a personal, offline Windows app.

- Markups: pen, highlighter, line, arrow, polyline, rectangle, ellipse, polygon, triangle, clouds, text box, callout, note, stamps
- Measure: calibrate, page scales (metric, architectural, engineering, custom), scale areas, length, polylength, area (+ depth → volume), perimeter, count, angle, radius
- Snap to drawing line work (endpoints, midpoints, intersections, along lines), ortho (F8), Shift for 45°
- Markups list with status, flags, filters, totals and CSV export
- Bookmarks (saved as real PDF bookmarks), page thumbnails, text search, My Tools
- Mouse wheel zoom at the cursor, double-click the wheel to fit the page, hold the wheel to pan
- Custom keyboard shortcuts (Help → Keyboard shortcuts)
- Markups are saved inside the PDF as standard annotations, so Bluebeam, Acrobat and browsers show them
- Check for updates from inside the app

Every push to `main` builds a new installer and publishes it as a GitHub Release. The commit message becomes the "What's new" text.
